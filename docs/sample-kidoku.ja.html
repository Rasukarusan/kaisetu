    How to use

    clickHover a diff line, the overview, an intent, or an AI note — press the + to comment
    copyThe button next to a file name copies its path
    ViewThe link at the right of a file header opens the whole file in a new tab: code highlighted and opened at the change, a Markdown or HTML file rendered as the document — "Source" then shows the code behind it
    j / kJump to the next / previous group
    RefreshTake the diff again once the code has been fixed — the groups, the explanations and your comments all stay, and every hunk that moved is badged "updated"
    SplitSide-by-side (old left, new right) or unified — drag the boundary between the sides to resize it, double-click to reset. The choice is remembered
    ExplainThe write-up of this branch for the team — one self-contained HTML file. Comment on it row by row like a diff line; "Open ↗" and "Copy file path" are how it leaves this page
    +Hover a paragraph, a heading, a list item or a table row — press the + in its gutter to comment
    pinOnce commented on, a row keeps a numbered pin in place of the +; click a pin or a comment to jump between them
    pToggle comment mode (turn it off to click links and buttons in the document)
    CommentsThe counter in the header shows / hides the comment column
    cCopy summary
    ⌘EnterSave while editing a comment
    EscCancel comment editing / close the comment list

    Comments are anchored to the row you pressed the + on. When the AI fixes the file, this page reloads with the new render within seconds and your comments stay put (a row that no longer exists is marked "anchor lost").

    Comments are saved automatically. "Finish" sends the results back to the agent session; the page stays usable after sending. When a comment receives an AI answer, use "Reply" to continue the thread, then press "Finish" again to send it back. When the AI rewrites the overview or an explanation in response to your comment, this page swaps in the new content automatically (your comments are kept). To hand the results to another session (e.g. Codex), use "Copy summary".

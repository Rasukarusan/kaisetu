    How to use

    clickHover a diff line, the overview, an intent, or an AI note — press the + to comment
    copyThe button next to a file name copies its path
    j / kJump to the next / previous group
    cCopy summary
    ⌘EnterSave while editing a comment
    EscCancel comment editing / close the comment list

    Comments are saved automatically. "Finish review" sends the results back to the agent session; the page stays usable after sending. When a comment receives an AI answer, use "Reply" to continue the thread, then press "Finish review" again to send it back. When the AI rewrites the overview or an explanation in response to your comment, this page swaps in the new content automatically (your comments are kept). To hand the results to another session (e.g. Codex), use "Copy summary".
